\# Wall-Following Robot V1



Arduino-based wall-following robot developed for educational robotics.



\## Project Structure



\- `WallE-Follower/`  

&#x20; Arduino source code.



\- `SchematicWallEV1/`  

&#x20; KiCad schematic and PCB design files.



\- `HC-SR04 Symbol for Kicad/`  

&#x20; Custom KiCad symbol and footprint files for HC-SR04.



\- `Pinout Images/`  

&#x20; Component pinout references.



\- `Robot Documentation/`  

&#x20; Robot documentation and reference images.



\- `Schematic V1`  

&#x20; Fritzing schematic image.



\- `Schematic V1 Fritzing.fzz`  

&#x20; Fritzing project file.



\## Hardware



\- Arduino

\- HC-SR04 Ultrasonic Sensor

\- Motor Driver

\- DC Motors

\- Robot Chassis



\## Features



\- Ultrasonic distance sensing

\- Autonomous wall following

\- Motor control

\- Educational robotics platform
